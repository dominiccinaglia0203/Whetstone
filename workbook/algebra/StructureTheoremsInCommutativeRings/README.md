In this problem we detail structure theorems for modules over two classes of 
rings; first PIDs then Dedekind domains. Then we introduce the distinction 
between Arithmetic Complexity and Homological Complexity for a given ring. 

Key Results Proven:
1. PID Structue Theorem for Modules
2. Torsion Invariants via Ext and Tor
3. Projective Ideals and Resulting Module Structure
4. The Class Group and Arithmetic Complexity
