In this problem we address key Homological definitions of modules over local rings,
and prove the Auslander Buchsbaum Formula which connects them.

Key Results Proven:
1. Local Rings, Localization, and Nakayama
2. Projective Dimension, Depth, and Ext Characterizations thereof
3. Depth Lemma
4. Auslander Buchsbaum Formula
Bonus: MCM Modules and Matrix Factorizations
