In this problem we begin with the notion of linear approximation of 
a function (linearization) on Euclidean space, and then we question
how changing the ambient space affects these approximations. 

Key Results Proven: 

1. Linearization in Euclidean Space

2. Global Linear Obstructions

3. Defining Manifolds and Maximal Atlases

4. The Tangent Space and Linearization on Manifolds

Bonus: Implicit Function Theorem and Regular Values
